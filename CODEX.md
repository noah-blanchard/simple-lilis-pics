# Codex Companion

Codex must use `AGENTS.md` as the canonical repository directive. Codex discovers `AGENTS.md` automatically; this companion exists as an explicit human-readable pointer and must not become a competing source of truth.

Before making changes:

1. Read `AGENTS.md` in full.
2. Read the relevant documentation under `docs/`.
3. For Next.js changes, read the relevant installed Next.js 16.2.7 guide under `node_modules/next/dist/docs/`.
4. Inspect the current implementation rather than relying on older framework conventions or the deleted `REFERENCE_PROJECT/`.

Follow the scope, security, workflow, verification, and documentation-maintenance rules in `AGENTS.md`. Put shared directive updates there, not in this file.
